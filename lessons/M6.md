# M6 — Scientific experiments with AI (2 × 50 minutes)
**Objective:** Compare trained detectors using held-out test images.
1. State a hypothesis, such as more diverse scenes improving recall.
2. Train two variants changing a single factor.
3. Choose checkpoints using validation data.
4. Run evaluate_m6.py on an independent test split.
5. Compare precision, recall, mAP50, mAP50-95 and failures.
6. Present limits, bias, privacy and deployment implications.
**Assessment:** A report with hypothesis, experimental control, metrics and limitations.
